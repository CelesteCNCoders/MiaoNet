# MiaoNet 反馈规范

Bug 和功能建议请提交到 GitHub Issues。提交前先搜索已有 Issue，避免重复；一个 Issue 只描述一个独立问题。中文和英文均可。

## Bug 报告

请至少包含：

- MiaoNet 版本和 Everest 版本；
- 操作系统及 Celeste 来源；
- 实际行为与期望行为；
- 可稳定执行的复现步骤；
- `Celeste/log.txt` 中问题发生前后的相关日志。

视觉问题请附截图或录屏；兼容性问题请列出相关 Mod 版本，并说明禁用其他 Mod 后能否复现。涉及服务端时，请同时提供服务端版本、运行配置（移除凭据）和对应日志。

示例：

```text
标题：使用 /tp 后游戏崩溃

MiaoNet：0.x.y
Everest：xxxx
系统：Windows 11

复现步骤：
1. 连接服务器并进入关卡。
2. 输入 /tp 玩家名。
3. 过场开始后游戏退出。

期望：传送到目标玩家所在房间。
实际：游戏退出，日志出现 NullReferenceException。

日志：
[MiaoNet] ...
```

不要只提交“无法使用”或整份无说明日志。日志中若含 token、Cookie、证书私钥、绝对用户路径等敏感信息，请先脱敏，但保留异常类型、堆栈和 MiaoNet 上下文。

## 功能建议

请说明使用场景、当前工作流的问题、期望行为和可能受影响的客户端/服务端部分。有参考实现时可附链接，但不要求先提供技术方案。

## 安全问题

认证绕过、远程代码执行、私钥或 token 泄露等安全问题不应公开附带可利用细节。请先通过仓库维护者提供的私密联系方式报告；若仓库未提供安全渠道，只公开最小必要信息并请求维护者联系。
