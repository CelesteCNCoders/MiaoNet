# MiaoNet反馈规范

感谢你愿意花时间反馈问题或提出建议！为了让维护者能更快地理解和处理你的反馈，请参考以下规范。

## Bug 报告

提交Bug时请包含以下信息：

### 必要信息
- **MiaoNet版本**：在游戏Mod列表中查看
- **问题描述**：发生了什么，你期望的行为是什么
- **复现步骤**：尽可能详细地描述如何触发这个问题

### 有助于定位的信息
- **日志文件**：`Celeste/log.txt`，出问题时的相关片段
- **截图或录屏**：如果是视觉相关的问题
- **其他已安装的Mod**：是否在禁用其他Mod后仍能复现
- **你的判断**：如果你有相关开发经验，你认为可能的问题原因
### 示例
```
标题：使用传送命令时游戏崩溃

MiaoNet版本：0.4.4
复现步骤：
1. 连接服务器
2. 输入 /tp 某玩家名
3. 游戏立即崩溃

期望行为：传送到目标玩家所在房间
实际行为：游戏崩溃，log.txt中报NullReferenceException

日志片段：
[MiaoNet] NullReferenceException at ...
```

## 功能建议

- 描述你想要的功能以及使用场景
- 如果有参考实现（如其他Mod的类似功能），可以附上链接
- 说明这个功能对你/其他社区成员的重要程度

## 注意事项

- 提交前请先搜索已有的Issue，避免重复
- 一个Issue只描述一个问题或建议
- 使用中文或英文均可
- 请保持友善和耐心，维护者会尽快回复
