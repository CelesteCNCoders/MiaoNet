# MiaoNet

CelesteNet 的一个重写, 以期望应对数以百计的蔚蓝联机玩家.  
称为 MiaoNet, 在可能与之前基于 CelesteNet 的 Miao.CelesteNet(也可能被称为 MiaoNet) 混淆时可以使用 MiaoNet+ 进行区分.  
目前该项目仍在早期的开发中(如你所见目前分支名也叫 `wip`). 尽管已经有了部分对外接口, 但仍然不太推荐过早去依赖它, 因为它仍然不稳定, 随时可能会进行破坏性更改.
